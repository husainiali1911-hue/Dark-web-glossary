DARK WEB ECOSYSTEM KNOWLEDGE MAP
========================================

[Forum] — 2 terms
  • forum avatars: Management of fake identities for accessing dark web communities
  • README file: Introductory post required in dark web forums for new persona verification

[Infrastructure] — 4 terms
  • mixer/tumbler: Service that anonymizes cryptocurrency by pooling and mixing transactions
  • .onion domain: Special-use top level domain suffix designating an anonymous onion service on Tor network
  • Tor circuit: Path through multiple relays that anonymizes traffic in Tor network
  • botnet: Network of compromised devices used for coordinated malicious activity

[Leak Site] — 1 terms
  • ransomware leak site: Platform where ransomware groups publish stolen data of non-paying victims

[Marketplace] — 4 terms
  • vendor shop: Individual seller storefront within darknet market
  • escrow: Third-party holding funds until transaction conditions are met between buyer and seller
  • dead listing: Inactive or removed listing on darknet market
  • market exit scam: Fraud where marketplace operators disappear with escrow funds

[Quality] — 2 terms
  • signal-to-noise ratio: Measure of useful intelligence versus irrelevant data in collected content
  • false leak: Fake or fabricated data release designed to mislead or damage reputation

[Ransomware TTP] — 3 terms
  • ransomware-as-a-service: Business model where developers lease ransomware to affiliates
  • double extortion: Tactic where attackers encrypt data and threaten to leak it
  • DDoS extortion: Threat of distributed denial-of-service attack unless ransom is paid

[Stolen Data] — 3 terms
  • stealer logs: Logs containing credentials harvested by info-stealer malware
  • credential dump: Bulk release of username/password combinations from breached databases
  • wallets-of-interest: Cryptocurrency wallet addresses linked to illicit activity

[Threat Actor] — 1 terms
  • initial access broker: Entity that sells compromised access to networks
